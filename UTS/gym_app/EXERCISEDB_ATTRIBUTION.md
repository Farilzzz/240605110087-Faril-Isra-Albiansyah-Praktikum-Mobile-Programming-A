# ExerciseDB OSS — atribusi dan penggunaan

Exercise library pada project GET FIT GYM (UTS) mengambil nama latihan, kelompok otot, instruksi, dan URL animasi dari ExerciseDB OSS oleh AscendAPI.

- Dokumentasi/API: https://oss.exercisedb.dev/docs
- Base endpoint yang digunakan: `https://oss.exercisedb.dev/api/v1`
- Endpoint daftar: `GET /exercises?limit=50`
- Media GIF berasal dari field `gifUrl` pada record latihan terkait, bukan dari URL yang dibuat atau gambar acak.
- Atribusi ditampilkan pada halaman daftar dan detail latihan.
- Penggunaan project ini bersifat pendidikan/UTS. Periksa dokumentasi ExerciseDB OSS/AscendAPI untuk ketentuan lisensi dan penggunaan terkini sebelum distribusi atau penggunaan komersial; jangan menganggap akses endpoint berarti hak redistribusi media tanpa batas.
